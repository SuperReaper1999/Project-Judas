# Judas Engine Alpha v1.2.4

Machine version **1.2.4-alpha.1**. This candidate includes the full committed
Experimental history following Alpha v1.2.3.

- JudasJS can read supported device tilt and request gamepad or Android handset
  vibration. Paused play suppresses script vibration. See the [input API](judasjs/input.md).
- Ragdoll joint validation accounts for model import scale.
- Advanced Fluid Dynamics remains locked in Alpha. The source includes the
  experimental wet-contact, settling and shared cut geometry work and its
  qualification evidence. The original basin remains unresolved on the research
  path. Basic Water remains available.
- The character recovery follow-up preserves the deferred prototype findings.
  The prototype get-up controller is outside the shipped runtime.

See the [previous patch](ALPHA_V1_2_3_NOTES.md) and the
[Alpha support matrix](ALPHA_SUPPORT_MATRIX.md).
