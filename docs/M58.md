## Shared runtime text path

`TextFont` retains immutable validated font bytes/revision. `TextEngine` resolves
logical UTF-8 into immutable `TextLayout` glyph/font identities, positions, lines
and real metrics. RuntimeUI measurement and Renderer submission consume this same
layout. Compatibility `DrawUIText`/`MeasureUIText` now delegate to it; old ASCII
FontLoader fixtures remain historical CPU tests rather than the runtime renderer.
Editor chrome remains Dear ImGui; selected runtime labels have a real Renderer preview.

Pinned local source inputs: FreeType **2.13.3**, HarfBuzz **10.4.0**, ICU4C **76.1**;
linked data **Unicode 16.0 / CLDR 46.0**. [Dependency provenance/licenses](../third_party/text/PROVENANCE.md).
Static common/i18n/full ICU data, FreeType and OT HarfBuzz; no runtime network,
Node, desktop font search or external ICU data folder. HB's optional FT/ICU bridges
and FT's HB bridge are disabled. C++17/OpenGL 3.3 baseline is retained. Full ICU data
is intentionally included; this is not a dependency-trimming project.

Pipeline:

1. Validate authored UTF-8; malformed runtime byte sequences become U+FFFD.
2. ICU paragraph bidi, script analysis, line and grapheme boundaries.
3. Ordered font selection: prefer complete script-run coverage, otherwise complete
   grapheme clusters; preserve surrounding paragraph context for HarfBuzz.
4. Shape each wrapped directional/script/font run; place visual runs per line,
   preserving glyph offsets, kerning, joining, marks and ligatures.
5. Resolve baseline from real font metrics and ink extents, then logical alignment.
6. Renderer rasterizes demanded glyphs with FreeType and batches consecutive atlas-page
   glyphs in ordinary UI draw order. No raw GL leaves Renderer.

Internal cluster indices are logical UTF-16 offsets, never byte offsets or a public
JS indexing promise. Source strings/keys are not normalized or reversed. Wrapping
uses ICU opportunities, including CJK without spaces. Long tokens use emergency
breaks only at both grapheme and shaped-cluster boundaries; otherwise overflow/clip.
Mandatory CRLF/newline/U+2028/U+2029 are supported. Logical start/end use paragraph
orientation; explicit left/right remain explicit. Missing coverage renders primary
`.notdef` with bounded diagnostics. Supplementary decoding does not imply emoji coverage.

## Bounded resources / rendering

Scalable Unicode outline TTF/OTF, first face only; max font 32 MiB. Text ≤64 KiB,
size >0 and ≤512 pixels. Native face cache 64 LRU entries, layout cache 256 LRU
entries, glyph lookup metadata ≤32768 entries, atlas ≤8×1024² RGBA8 pages (**32 MiB**).
Usual menus use one 4 MiB page. Individual raster glyphs above 1020×1020 are
diagnosed/skipped; reduce their font size. Layout keys include exact source, locale, direction,
alignment, wrap width, size and ordered font revisions. Cached layouts retain glyph
IDs/font bytes, never stale GPU UVs. Atlas retirement flushes pending batches before
reusing storage; retained layouts safely rerasterize after eviction/reset.

Font faces/layouts belong to their owner thread; resource workers only decode
immutable font/catalog data. GPU resources belong to Renderer. Fonts follow ordinary
resource demand, generation cancellation and reference lifetimes. ASCII-only projects
request no Noto families; the engine's existing packaged DejaVu remains the default.

Grayscale coverage is alpha, with white RGB/transparent atlas gutters. Text uses the
normal alpha UI pass **after** world tone mapping, with normal clipping/reference
resolution scaling. It is exposure-independent, not a PBR/sRGB color texture.

## Catalogs and runtime locale

[Complete public API and syntax](judasjs/localization.md) · [types](judas.d.ts).
Normal stable-ID `.judasloc` assets use `JudasCatalog 1 "locale"` and quoted key/message
pairs. Keys are stable project identifiers (use `table.key` convention). ICU named
MessageFormat supports plain/string, finite number, `number`, `plural`, `selectordinal`
and `select`. Arguments are data, never templates. Dates/time/choice/positional
arguments are rejected. Duplicate keys and malformed UTF-8/patterns reject import.

Project settings contain canonical BCP 47 default/available tags, catalogs, explicit
fallback chains and ordered global/per-locale font IDs. Fallback is requested tag →
configured chain → registered parents → default chain, deduplicated; cycles reject.
Resolved templates use their **catalog locale** for plural/embedded number rules;
`localization.number` uses the **published display locale**, never host locale.
Missing keys show `[key]`; invalid/missing arguments throw JS TypeError. Limits and
ICU apostrophe escaping are documented in the reference.

LocalizationSession belongs to the project Play/session. A language request waits for
all demanded catalog-chain/font resources, then publishes coherently with a revision.
Invalid replacement retains previous texts. Reload validates asynchronously. Scene
replacement/reload retains session locale; Stop/project replacement creates fresh
authored defaults. This adds no persistent user settings or new save system.

Static UI `textKey` binds a no-argument caption; assigning JS `.text` clears that key.
Assign `.textKey` to restore binding. Dynamic HUD scripts cache formatted text against
message inputs and `localization.revision`. `uiUpdate` works during pause. Direction
inherits from parent (`auto` uses paragraph analysis at root); explicit `mirrorRow`
mirrors horizontal child placement in RTL locales, not images, world axes or input.
Focus order remains authored order. New fields emit UI format 2; old documents retain
format-1 serialization when unused. Project format 1 and fingerprint schema 5 remain.

Authored catalog/font bytes and stable IDs/configuration extend the baseline only for
localized projects. Transient locale, formatted text and GPU/layout caches never enter
saves. Legacy non-localized project identity remains unchanged. Project-relative
resolution preserves identical fingerprints when a project/package is moved.
The final numeric-locale regression also pins InputMap/navigation authored streams to
classic numeric format, fixing their older inherited-locale parsing/serialization
defect without changing gameplay, baked navigation content or schema.

## Editor / prefab / export workflow

1. Import TTF/OTF and UTF-8 `.judasloc` files into ordinary Assets (or rescan).
2. Project Settings → Localization: choose default, add canonical locale tags, select
   catalogs/fallbacks and ordered font assets (add, move up, remove).
3. Open a `.judasui` asset: author literal/key, font, direction, named alignment and
   optional row mirroring. The selected label's preview uses the real shaped Renderer.
4. Open a catalog in Asset Browser's UTF-8 source editor, validate/save, then reload
   preview/runtime catalogs. Translation editing needs no C++ rebuild.

UI document references remain ordinary prefab component properties/overrides.
Export uses existing all-registered-runtime-assets policy and validates localization
references/header tags first. Font/catalog files and license notices are included;
all Unicode libraries/data are static in the Release runtime. Existing Linux SDL2,
OpenGL, glibc/libstdc++ system dependencies remain. No arbitrary system folders copied.
Runtime packages omit development docs/typings; developers obtain them from `docs/`.

## Current demonstrations

### Unicode lab

[Project](../projects/text_lab/text_lab.judasproj), scene `Scenes/lab.judas`, document
`Assets/ui/lab.judasui`, script `Assets/scripts/lab.js`. Six configured locales:
English, German, Arabic, Japanese, Russian and Hindi. Buttons select language; Reload
catalogs retries edited sources. No pointer capture. Resize normally.

Latin accents/decomposed marks, Cyrillic, Arabic/Hebrew with Latin/numbers, Devanagari,
horizontal Japanese, supplementary 😀/𝔸 and intentionally unsupported U+10FFFF.
DejaVu lacks Indic/CJK coverage, so fallback is genuinely exercised. Expanded/narrow
text, explicit missing-key fallback, plurals and locale numbers are included.
Noto/DejaVu font commits/hashes/licenses live beside project fonts. Translations are
**demonstration content, not native-speaker reviewed**.

### Localized Spring Range

[Project](../projects/shooter_game/shooter_game.judasproj). Existing game mechanics,
physics, score, materials and navigation remain unchanged. HUD, controls, instructions
and pause captions use English/German/Arabic/Japanese catalogs. **L** cycles languages
while playing or paused; pause menu also has a Language button. Escape pauses/resumes.
WASD, mouse aim, fire, jump, camera toggle and restart retain existing project bindings.
HUD language policy is only `Assets/scripts/hud.js`; no game-specific engine translation.
Arabic/Japanese font families are demanded only for those configured locales.

## Honest limits / human review

Horizontal outline grayscale text only; no color/SVG emoji, font collection face
selection, vertical writing/ruby, rich text, advanced justification/hyphenation,
text entry/IME/caret/selection or automatic translation. Fallback cannot synthesize
missing glyphs; cross-font cluster/run selection is not a universal typography claim.
Arabic/Indic/mark samples have independent pinned-tool evidence; languages/scripts
outside these samples are not independently certified. UI chrome is not localized.
Catalog editing is UTF-8 source editing, not a translation-management platform.

Human review: read lab/mixed-direction numbers/fallback; resize and inspect wrapping,
marks/baselines/clips; change Spring Range language in play/pause and continue same
round; check score/plurals/numbers/RTL menus; edit/reload a catalog; test Stop/reload
and moved standalone, inspect M56 cost. Human visual/gameplay acceptance is authoritative.
