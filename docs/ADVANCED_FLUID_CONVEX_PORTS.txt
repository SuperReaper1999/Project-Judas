1. PHYSICAL CELLS AND ACTUAL PORTS
Stage16's compact merged pressure cell showed excessive dynamic resistance. The
new prototype keeps convex physical fluid pieces and actual pairwise apertures,
with positive integration tetrahedra serving integration only. Every actual wet
component, native solid face and shared fluid opening has an explicit owner.
Exact rational physical geometry is checked independently against the frozen
six-tet reference, including true solid apertures and normals, background quad
apertures, volume/first/P2 moments and disconnected components. Missing-face
negative controls fail. No tiny volume is removed or repaired.

Treating integration tetrahedra as physical cells created artificial cells down
to ~1.8e-34 m3 for an ordinary .4 m box at a tiny rotation. Using the original
voxel as the background physical cell removes THAT artificial-diagonal problem:
central-box hydrostatic velocity ~6e-21 m/s, minimum piece volume .048 m3, proper
2.56 N s buoyancy. This does NOT remove real voxel-boundary slivers.

Sequential first-exclusion cuts also bias a coarse cubic physical response:
299.354/216.549/117.595 kg along the three axes in the measured fixture (44.3%
normalized directional bias). A separate symmetric partition uses
  f_i(x) = n_i dot x - d_i
  P_i = voxel intersect {f_i >= 0} intersect all_j {f_i >= f_j}.
Exact differences of original plane coefficients are essential; rounding those
differences can destroy transitivity. Six convex regions partition the SAME
physical exterior. Exact tie ownership handles dominance/grid-plane coincidence.
Changing the order of native face pairs leaves the response tensor unchanged to
4.6e-17; the axis fixture gives 143.34 kg in all three directions. This removes
ordering bias in the PROTOTYPE. It is not continuum added-mass certification.

Independent symmetric geometry: 136907 exact checks, ten fixtures, 187 paired
ports, including the genuine tiny-angle voxel corner. Own symmetric tests: 706
checks. Separate physical work tests: 97 checks, actual body+wall+fluid impulse
balance <=8.89e-18, work derivative error <=1.25e-16. Related ordering and
covariance checks are not counted as dynamic-resolution accuracy.

5. ACTUAL TIME-INTEGRATED TRANSLATIONAL WALL GEOMETRY
Endpoint overlap alone misses out-and-back motion. The new exact reference finds
combinatorial events of fixed-normal affine translating native planes in each
voxel. Between events vertices are affine in time; oriented surface areas are
quadratic and their first-position moments cubic. Exact interior quadrature
integrates native wall volume AND first-moment flux over the actual path.
It verifies, per voxel,
  integral wallVelocity dot n_solid dA dt = Vsolid(new)-Vsolid(old)
  integral x (wallVelocity dot n_solid) dA dt = Msolid(new)-Msolid(old).
The second identity verifies arbitrary-uniform-gravity potential work. An actual
exact reversed path cancels each voxel's exchanges while retaining both legs;
ignoring events demonstrably misses swept volume.320 final checks pass.

Exact halfspace certificates discard inactive four-plane events, preserving the
same identities. Oblique example348->80 intervals, time3559->~944ms; tiny corner
192->28,2250->~574ms. These are offline exact-reference timings, not runtime fluid
speedups. Rotating normals, solved trajectories, displaced-water routing and a
coupled GCL/momentum time integrator are NOT implemented by this geometry proof.
