1. **Composed persistence/stream lifecycle:** Save with streamed motors, mapped
   articulations, moving anchors and runtime classification changes together;
   exclude/reinclude one owner, unload/revisit and cold-restore. Independently
   inspect geometry, physical endpoint and safe-handle publication after each
   boundary. Existing isolated passes do not prove this full composition.
2. **Modded runtime/save/export ownership:** Exact-trust publication through real
   Application/QuickJS imports and contributed prefabs; disabled/missing/changed
   package during load; retained-session resources under async streaming; moved
   standalone package with the selected loadout. New native storage tests do not
   discharge this matrix. Use disposable roots, never real user installations.
3. **Resource revision and cancellation:** Skeleton/model/navigation/UI replacement
   while asynchronous work and runtime references are live; Stop/project switches
   during publication; broken dependency/source inputs must fail privately. Trace
   final ownership and actual observers, not merely successful job counters.
4. **Shared final-pose composition:** Multiple conflicting/unreachable IK chains,
   joint limits, socket/root interactions and physical drive transitions; save and
   asset replacement. Tiny analytic and single mapped-body proofs pass only their
   specific geometry. No synthetic claim that active balance or all anatomy works.
5. **UI restore and physical editor/input:** Actual scene transition and save UI
   state, layout clipping/anchors/all widgets, localization/fonts, pointer focus
   and real editor undo/copy-paste/batch authored references. CPU hit geometry is
   verified; pixels, OS pointer capture and editor gestures are not.
6. **Storage fault/concurrency/platform matrix:** Process termination, full disks,
   symlink/reparse/hardlink races, cross-process leases and concurrent installers.
   Exception injection tests only named boundaries, not power-loss durability.
