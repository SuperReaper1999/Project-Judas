## Readiness and remaining boundaries

The unchanged reimport shortcut does not weaken normal cooked decoding or exporter
validation. Cache receipts contain the accepted output hash, import provenance and
its hash. Missing/corrupt receipts fall back to full validated decode. Base/motion
payload caches have hashes and reconstruct from sources/recipes. Publication stamps
are race guards, not cache keys. Archive version 1, named schema 1, project format 1
and canonical fingerprint schema 5 remain unchanged.

Normal ResourceManager admission is at most three CPU/private-GPU tasks, with a
file-size-based decoded estimate against the existing budget. Completed CPU work
retains admission until publication/discard; one oversized request progresses alone.
This bounds work, **not actual decode expansion or safety-pinned resident memory**.
Queue metadata can grow with caller demand, and FIFO admission can delay later work.

Normal Pump shares a 2 ms soft budget. Geometry/material-map work yields before
the next unit; partial mesh/skeleton state never publishes. The existing explicit
blocking harness/reference/physical-resource paths remain blocking. Actual desktop
GL instrumentation traced a remaining ~99 ms material-map unit to ~22 ms texel
upload plus ~77 ms mipmap generation; geometry was ~14 ms and final installation
~12 ms. This is a measured indivisible-driver boundary, not a hard-budget success.
Cancellation/re-request ready latency includes two full original asset decodes and
is approximately 6 seconds. Full completion latency is reported, not just submission.
The clean desktop-GL gate measured 74.31 ms maximum Pump; two later mechanism
repeats measured 78.73/73.79 ms, six private-upload frames and 5.74 s readiness
including cancellation. Both unload to zero bytes. The earlier ~99 ms unit remains
the worst observed map upload. The baseline blocking install was ~397 ms, but its
single-load workload is not identical to the cancellation/re-request test.

Short real-clock normal game captures retain final 120 frames plus bounded spikes:
Skate/Rooftop/Void outer-frame medians are **2.41/2.46/5.09 ms**, p95
**3.59/3.25/7.69 ms**. Raw maxima **124.92/61.40/70.97 ms** include the observer's
final synchronous screenshot/report, rather than being hidden. No catch-up cap or
discarded fixed time appears in retained frames. These are short instrumented idle
samples, not human FPS certification or a comparable before/after game benchmark.
See [REAL_TIME_PROFILE_SUMMARY.json](REAL_TIME_PROFILE_SUMMARY.json) for aggregate
frame, fixed-step, resource, streaming and render scopes, counters and provenance.

Streaming timings have mixed/noisy changes; no general streaming speedup is claimed.
Measured coherent units remain below 2 ms. Required relationship/region scans,
serialization, geometry and callbacks remain real work. No safety pins or retained
state were discarded to improve counters. Whole-scene editor history still costs
memory proportional to content × retained revisions; the existing 200 limit remains.
