WHAT IS ACTUALLY WRONG
---------------------
1. A local triangle impact can retire CCD for its whole concave mesh. The rest
   of that mesh is not the same support plane: the body can reach another
   finite face. The reduced16-triangle original fixture still fails; sheer
   triangle count is not the correctness cause.
2. Native one-sided selection uses the mean represented body vertices. That
   mean can pass behind a triangle while the body still has real finite front
   contact. A stateless subsequent query then loses that continuing contact.
   Always-front, two-sided or infinite-plane rules would invent invalid rear
   and finite-edge contacts.
3. Repeating checks more frequently is not sufficient. The mesh-repeat trial
   still fails all four original assertions. A tighter facet depth limit
   repeatedly schedules the exact same time after velocity response stops
   changing. It stalls rather than producing valid time progress.
4. There is avoidable numerical work. Independent interval evaluation loses
   correlations between shared body centres, projection origins and rotation
   columns. The represented geometry is fine; its conservative enclosure is
   much too wide and repeatedly subdivides the same physical episode. Earlier
   valid checkpoints on the SAME trajectory can also avoid replaying ancestry.

WHAT THE ISOLATED REPAIR DOES
----------------------------
It carries selected front ownership for actual finite contact components,
advances that state chronologically, expires ownership at real finite gaps,
and permits ordinary independent native-front re-acquisition. Static topology
only excludes impossible transfers; belonging to the same mesh never grants
ownership. Same-path checkpoints are derived acceleration state, not physical
truth.

The interval certificate preserves common-centre, common-projection-origin
and common-rotation-column correlations while retaining explicit rounding
error envelopes for original native operations. These are sufficient-only
certificates: uncertain arithmetic is not collision truth. The original
1024-interval/depth40 policies, geometric cutoffs, physics timestep, tests,
materials and solver budgets are unchanged. Research headers still have four
misleading-indentation warnings; this is not a release-quality integration.

A captured suffix that required509 interval nodes/255 certificates now needs
127/64 after the first algebraic correction and33/14 with chronological proof.
The final rotated capture changes from uncertainty at1025 visited nodes to a
completed proof at927 nodes/460 certificates. Vertex/centre/nearest-origin
heuristics alone do not fix that rotated capture. These are proof-work counts,
not whole-engine speedup measurements.

INDEPENDENT NEGATIVE TEST: NEW PROTOTYPE REGRESSION
-------------------------------------------------
The paired worlds have identical original launches, same distant inert box
and awake prefixes. Only actor-versus-inert collision suppression changes.
Baseline:1681 checks/0 failures; no physical changes despite observation
invalidation. Candidate no-op:1681/0; no physical changes. Candidate unrelated
filter edit:1681/3; three physical changes, one crossing. Disabling the actual
sheet pair changes physics as expected in both binaries, proving the observer
can detect a genuinely removed mechanism.

Failed launch/prefix pairs are17/6,5/7,17/7. The17/6 case reaches13.3019cm
behind the actual sheet after four suffix steps; the unchanged control stays
on the other side. There are no exceptions. See
lifetime-controls/LIFETIME_FAILURE_SUMMARY.txt and raw logs.

Cause: the prototype borrows contactObservationRevision as physical ownership
lifetime. SetPairCollisionEnabled increments this body-wide revision even for
an unrelated pair. The still-valid sheet episode becomes inaccessible, and
native sidedness cannot reconstruct it from the now-behind-centre pose.
Simply ignoring all revisions would introduce other reset/filter/reuse bugs.
Physical ownership needs its own explicit lifecycle.
