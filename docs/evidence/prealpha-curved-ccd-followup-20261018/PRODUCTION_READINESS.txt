SOURCE-ONLY COST ASSESSMENT (NO OPTIMIZATION OR ATTRIBUTION MEASURED)
There is no source basis for declaring finite-contact ownership intrinsically too
costly. The implementation repeats work that can be reused exactly, while a broad
actual contact patch and difficult interval proofs can still be expensive:
* R/sources/MeshUnionContinuity.h:42-50 scans/allocates for the entire immutable
  mesh topology on every ForwardEpisode call (:144), even for a tiny contact patch.
  Cache these exclusion labels by validated immutable topology identity. They
  exclude impossible transfer; reusing them must not grant actual finite contact.
* The same helper reconstructs finite components and native selection at the
  initial/endpoint (:147-149) and repeatedly at each recursive endpoint
  (:160,166,168,174). CollisionGeometry.cpp:398-409 rebuilds the query polytope,
  candidates, SAT and connected traversal on every call. A query-local prepared
  endpoint could retain the exact native finite set and shared-edge graph, then
  answer seed/component operations without repeated geometry evaluation. Preserve
  represented pose, SAT/sidedness predicates, feature order and topology identity.
* NativeFrontFeatures recomputes the represented vertex mean for every returned
  facet (MeshUnionContinuity.h:12-22); its operands are shared at a fixed endpoint.
  CollisionGeometry.cpp:407 uses a linear visited lookup inside adjacency walks;
  exact membership storage can avoid quadratic connected-patch work.
* EpisodeForTime runs MeshEndpointUsesNativeSelection before consulting an exact
  derived checkpoint (physics/WorldInternal.h:563-571); repeated same-time queries
  can therefore repeat the full endpoint native-completeness query. Any reorder
  needs explicit cache validity and return semantics, especially native-complete
  checkpoints that intentionally return no sideband episode.
These are candidates for later measurement, not demonstrated causes or promised
savings. Per-contact-patch work and subdivision can remain after removal of the
avoidable whole-mesh scan. Do not enlarge budgets, loosen contact policy or ship
the regression to obtain a performance claim. Preserve this handoff now.
