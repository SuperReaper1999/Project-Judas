Established cause
-----------------
Within an anchored segment the intended COM is linear and the dynamic Cayley
quaternion numerator is linear in elapsed time. Native EvaluateGeometry casts
elapsed time to float, rounds each COM coordinate to float, rounds quaternion
operations, then usually normalizes to float. Exact downstream predicates
correctly classify these rounded poses, but those sampled rounded shapes can
jump from separated to penetrating although the smooth source trajectory is
still separated. This fabricates new arrivals, repeatedly invoking the whole
connected contact island. Some toggles involve one center-coordinate ULP;
most tiny quaternion toggles involve one raw numerator component ULP rather
than every component changing during normalization.

smooth-gap-proof.py independently evaluates all 15 OBB SAT signs with Python
Fraction from exact captured IEEE inputs. R(q)=R_raw(q)/dot(q,q) is rational,
so no normalization square root or geometric epsilon is needed. Independent
SAT on native represented poses agrees with native PairTouches for every
probe. Of the 14 selected native TOIs:
 - 12 smooth trajectories are separated at both start and native TOI.
 - 2 smooth trajectories already overlap at both start and native TOI.
 - Float elapsed versus double elapsed is negligible in these examples;
   COM-coordinate and orientation-component rounding both contribute.

interval-separation-proof.py closes the important endpoint-only gap. It
chooses fixed separating planes on exact dyadic subintervals. Each of 64 OBB
corner-pair gaps is multiplied by the two positive quaternion squared norms,
leaving a degree <=5 exact rational polynomial. Every Bernstein coefficient
is strictly positive. Thus all 12 separated cases are certified separated for
EVERY time from the original query start through the native reported arrival
(and the tiny final replay probe beyond it). Each proof takes 1-4 leaves and
maximum depth 2. These are genuinely false arrivals under continuous anchored
motion, not hidden transient contacts between endpoint samples.

Example: event 16, replay record 21, has smooth normalized maximum gap about
+220.11 nm at query start and +220.80 nm at the native arrival while the native
represented pose reports about -4.20 nm. The whole interval is separated.
Event 44 has smooth gap about +210.85 -> +211.79 nm while native reports
about -15.68 nm.

Crucial limits and failed approaches
-----------------------------------
The all-time certificates above cover START TO NATIVE ARRIVAL, NOT the whole
remaining fixed step. full-interval-separation-proof.py finds smooth overlap
at the requested fixed-step endpoint in ALL 14 cases (about 0.09-0.55 mm).
Dropping these pairs or returning no-hit for the entire interval would be
incorrect. A repair must re-time genuine future collision after certified
prefix advancement, or use continuous motion consistently for TOI truth.

The first fixed plane chosen only at query start was too weak; preserved in
fixed-startplane-nonproof.*. Choosing midpoint planes and at most depth-2
subdivision establishes the short-prefix results without changing geometry.

smooth-arrival-brackets.py was a bounded exploratory diagnostic, INTERRUPTED
by its owner after three completed records. It has a partial log and source,
NOT a complete JSON result. First record's genuine smooth overlap bracket is
about 0.248369 ms versus native false arrival 0.233501 ms; a prefix through
0.245887 ms was fully certified. However longer prefixes can require many
fixed-plane leaves (138 leaves/depth 9 in the second record), and nonmonotone
rotating geometry makes ordinary global bisection insufficient to prove a
FIRST arrival. This warns against unbounded recursive polynomial work.
Do not interpret the later pointwise bracket as a first-arrival certificate.

Recommended correction boundary
-------------------------------
A generic private continuous-trajectory separation/advancement certificate is
justified if it covers only explicitly proven intervals and re-searches the
remainder. Restrict the first supported domain honestly; unsupported shapes,
invalid range, segment-boundary crossings and uncertain arithmetic must retain
the existing CCD path. No velocity-only culling, distance epsilon, enlarged
slop, contact caps, TOI caps or whole-pair dropping is justified.

The geometry-time authority must be explicit: continuous anchored motion
versus rounded public/body pose observations. A native-candidate guard can
remove demonstrated false arrivals but is not a full continuous-CCD overhaul;
actual smooth first-contact versus native-manifold availability remains a
boundary to validate. Already-overlapping smooth start states must be treated
as existing contact episodes with real future finite-feature/penetration
checks, not simply ignored. Exact behaviour and performance of a final repair
are not established by this investigation.
