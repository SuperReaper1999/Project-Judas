## What the records establish

- `modern/` and `portable/`: complete, provenance-checked 31-gate runs. Each
  `RESULTS.json` records executable hashes before/after, embedded identity,
  commands, scope and individual results.
- `final-measurements.json` and `final-970c8296/`: three short actual-game runs
  plus a 24,576-frame traversal. Compressed JSONL files retain every measured
  frame, including the asynchronous excavation period. RSS and stderr are
  separate. `run.py` records the actual commands used on this host.
- `before-invalidation/`: exact 376b0a8a runs on the same input. They preserve
  the repeatable 78–80 ms p95 edit-frame problem, rather than measuring only
  after the queue settles. The correction retains unchanged GPU images/meshes;
  it does not lower terrain resolution or alter collision.
- `sdk-{sdk,flat,planet}/`: packaged-SDK project creation, actual editor Play/Stop,
  tool operations and relocated games, including real cross-chunk tunnel
  traversal, raise/paint, navigation, cold saves and consumed particle impacts.
  These candidate runs use exactly the final engine binaries. The final
  documentation-refreshed SDK gets separate verification receipts.
- `provenance.json`: exact source identity and preservation boundaries. The
  local build is truthfully dirty because of unrelated PNGs and the working
  note. All compiled engine/tool inputs match the committed source. This is
  not a clean-machine or reproducible-release claim.

The earlier checked-cave-spill comparison and deliberately undersized 128 KiB
sample-cache thrash are retained alongside these records. Previous structured

## Reproduce

Use a fresh build/fixture/output when identity or fresh-directory guards request
one. Do not delete previous evidence to reuse a name. With current configured
Experimental binaries:

```sh
cmake --build build -j2 --target judas_prealpha_tests judas_terrain_v2_game_benchmark
SDL_AUDIODRIVER=dummy python3 scripts/prealpha_validate.py --build-dir build \
  --group terrain --test renderer-shader-library --output .cache/terrain-review-new
SDL_AUDIODRIVER=dummy JUDAS_GL_PROFILE=portable python3 scripts/prealpha_validate.py \
  --build-dir build --group terrain --test renderer-shader-library \
  --output .cache/terrain-review-portable-new
```

The one-kilometre measurement fixture is generated by the retained
[`prepare_case.py`](../structured-collision/prepare_case.py); supply a new
`--output` directory. Its byte hashes are recorded in `input-hashes.json`.
Build the normal public tools first if they are not already available.

```sh
python3 docs/evidence/terrain-v2/structured-collision/prepare_case.py \
  --output .cache/kilometre-review-new
SDL_AUDIODRIVER=dummy build/judas_terrain_v2_game_benchmark \
  .cache/kilometre-review-new/terrain_v2_workshop.judasproj --traverse
```

This visits every native chunk three times, asserts the actual runtime camera,
queries collision independently of that camera, and measures ordinary render
submission/GPU elapsed time. It runs without real-time pacing and includes
synchronous GPU timing, so reported milliseconds must not be labelled game FPS.
Do not run compilation or other GPU workloads during a performance comparison.

SDK-only qualification needs no development source tree:

```sh
SDK=/absolute/path/to/the/matching/sdk
python3 "$SDK/tools/package_sdk.py" verify "$SDK"
python3 "$SDK/tools/validation/qualify_terrain_v2.py" --build "$SDK" \
  --output /tmp/terrain-flat-review-new --material-detail --particle-region
python3 "$SDK/tools/validation/qualify_terrain_v2.py" --build "$SDK" \
  --output /tmp/terrain-planet-review-new --material-detail --planet
```

The driver parks its editable source before launching the relocated package from
an unrelated directory. Native cook receipts and exported material dependencies
are checked, then separate processes restore and continue actual gameplay.
Existing project assets, save directories, research and installed SDK selections
are preserved. Platform/hardware claims are limited to the recorded scopes.

Selected full-resolution views are retained here. Every captured frame and the
