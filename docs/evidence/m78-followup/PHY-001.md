# PHY-001 derivation and development record

The first scheme below is **HISTORICAL — superseded by the midpoint predictor described later in this record**. Its failed energy measurements are retained. The working candidate uses midpoint prediction plus endpoint momentum transport.

## Historical first-order proposal (before measurements)

Let R(q) map body to world, I_b be the body inertia, I_w = R I_b R^T, omega_w the public angular velocity, and L_w = I_w omega_w. Euler rotation obeys dL_w/dt = tau_w; equivalently I_w domega_w/dt = tau_w - omega_w cross (I_w omega_w). Existing code omitted the transport term.

Chosen bounded correction preserves the established anchored normalized-Euler quaternion trajectory used by CCD. During each force-free drift, recover L_w at the segment anchor, advance q using the existing expression, then recover omega_w = I_w(q_new)^-1 L_w. Torque kicks change L by tau dt; impulse APIs retain their existing inertia response. No persistent additional momentum state or save schema is required. This is first-order orientation integration, not an exact Euler-top solution or an energy-preserving midpoint method. Angular momentum vector is preserved up to represented float state; energy error must decrease approximately first-order under refinement. The preliminary second-order expectation in ACCEPTANCE.md applied only if midpoint were selected, which it was not.

Motion queries keep their original geometric trajectory, but report transported physical angular velocity. CCD closing/curvature bounds must continue using the segment's anchored drift generator (not the transported endpoint velocity); a Cayley-normalized Euler path turns no faster than its generator. At an actual impact, material angular velocity is transported to the event orientation before solving, and a changed velocity creates a fresh segment. Kinematic prescribed velocities remain unchanged.

Declared checks: world momentum vector <1e-4 relative over 2 seconds at all four original cadences; energy reported separately and decreases with refinement; rotated equivalent and sphere controls; torque/impulse expected delta L. Contact/constraint conservation remains approximate and is measured separately.

## First-order experiment and refinement decision

The first candidate preserves world L to <1.6e-6 relative but exhibits 11.612% peak energy error at 60 Hz, falling approximately first-order to 1.289% at 480 Hz. Those receipts are retained. This is too coarse for the intended correction. Before subsequent measurements, select an explicit midpoint angular-generator predictor: alpha = -I_w^-1(omega cross L); generator = omega + dt alpha/2. Use the same anchored normalized-Euler/Cayley rotation with this constant generator, then reconstruct endpoint omega from L. Free rotation is now second order; torque kicks remain first order. CCD bounds use this generator and its existing curvature proof, so they still enclose the actual geometric trajectory. Require <0.5% free-body energy error at 60 Hz with second-order refinement, in addition to the declared momentum tolerance. No empirical damping or spin clipping.
