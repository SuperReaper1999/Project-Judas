Qualified native change
-----------------------
PhysicsWorld::VelocityCoupling::ForEachSubstep supplies the existing native
chronological interval, local solve iteration and an optional completed-boundary
observation. Existing whole-Step callbacks retain their convention. A legacy
single solve only addresses the first acceleration increment, not all four
chronological intervals; a new participant must not guess these timings.

The helper changes no integration/collision algorithm. It is not a scene mutation
hook, a universal coupled-solver convergence guarantee, CCD boundary registration
or full-world failure rollback. Independently compiled native clients must rebuild
because VelocityCoupling's layout changes. No JudasJS API was added.

Solver evidence and performance scope
-------------------------------------
Dense rank-aware reference passes buoyancy controls but costs400-550 ms per tiny
solve. A unilateral projected iteration capped256 and is rejected. Increasing a
reference-only budget exposed an equilibrium, not a production-budget solution.

The sparse trial keeps body motion as an exact low-rank update rather than a dense
pressure-row clique; precomputes fill indices; invalidates changed topology; and
reuses a factor only when its complete numeric source is identical. An equality
candidate is accepted only after EVERY non-pulling multiplier and the complete
current physical KKT residual pass. Otherwise it falls back to the bounded
inequality solver. No fictitious compliance, energy clamp, damping or regularizing
physical diagonal is added. A singular candidate is rejected explicitly. The
barrier solver remains available for disturbed/separating configurations.
