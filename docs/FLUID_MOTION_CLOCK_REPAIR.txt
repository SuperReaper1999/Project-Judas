CONFIRMED ROOT CAUSE
Production fluid updates normally run at30Hz while rigid steps run at60Hz.
The adapter concatenates the resolved rigid paths into one fluid interval.
It shifted segment.begin/end by the accumulated offset, but left the anchored
translationTime in the original rigid-step clock. The evaluator computes
  position = translationOrigin + velocity * (time - translationTime).
The second segment therefore extrapolated an extra rigid interval, then snapped
back to the stored endPose. Differencing those sampled poses supplied fictitious
wall velocities to the water. Existing native MK2/coupled-step adapters already
shift all three clocks; the fluid adapter had missed the translation epoch.

Actual-pool trace: one wall contact was given about18.5m/s longitudinal speed
while its actual rigid body moved about7.4m/s. A later corner response accelerated
a tracked particle upward to70.1m/s within a fluid substep. Passive pressure
reconstruction accounting showed only micro-m/s subtraction residuals; this was
not evidence for replacing binary32 with an expensive pressure backend.
