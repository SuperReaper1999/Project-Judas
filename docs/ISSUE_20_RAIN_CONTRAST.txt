CONFIRMED CAUSE / CORRECTION
----------------------------
The v1.0.1 lighting correction correctly removed fixed daylight illumination.
Rain then used its lit blue colour as opaque-surface alpha coverage:
  C_out = alpha*C_rain + (1-alpha)*C_sky.
When C_rain approximately equals C_sky, the visible contribution tends to zero.
Some channels even darkened. This reproduced with the supplied squall/storm
profiles in both linear/HDR and legacy rendering. The previous45 lighting
assertions passed while six newly added precipitation assertions failed.
This is an engine presentation regression, not a faulty Flight Sim input/profile.

The small correction uses alpha-weighted additive LIT highlights for thin rain
streaks and splashes:
  C_out = C_sky + alpha*C_rain.
Rain retains the existing actual ambient/sun/flash illumination, depth and shelter
rejection, bounded counts, shape, wind and arbitrary-up motion. No emissive
minimum or whole-scene brightness adjustment is added. Snow and tornado debris
explicitly keep normal alpha coverage, including when mixed with rain. Target
alpha is preserved for rain highlights; snow/debris keep the previous alpha
equation. End-of-pass blend-state restoration remains in place. No new public
APIs, project settings, game-side workaround or physics/quantity change.

This is a deliberate inexpensive scattering-highlight approximation: real
droplet refraction/extinction and multiple scattering are not simulated. It does
not undo the dusk/night fix or reintroduce a fixed daylight sky.
