# Wheels and suspension

The current implementation is [Vehicles / Wheels V2](VEHICLES_V2.md). That document covers finite-width support, MK2 constraint integration, tyres, sleeping, authoring, diagnostics, persistence and modelling limits.

Use the [JudasJS wheel reference](judasjs/wheels.md) for exact script fields and the [powertrain reference](POWERTRAINS.md) for shafts, engines, gears, clutches and differentials.

The original M81 implementation and acceptance evidence remain available in [Git history](https://github.com/SuperReaper1999/Project-Judas/tree/2ee4203a0053cc545eab4a184c627f4f5507c4bd/docs/WHEELS.md). Those historical sphere-contact and one-pass scheduling descriptions are not the current V2 runtime contract.
