EQUATIONS / NUMERICAL BOUNDARY
------------------------------
The unchanged reference problem remains
 min_q 1/2||Aq+BV-b||^2,  Dq+E V=0.
Conservation is eliminated BEFORE kinetic minimization, not repaired afterward.
The physical field, volume flux and native reaction derive from the same
wet-volume kinetic functional. The final path uses Stage9's original prepared
QR implementation and field reconstruction.

For clarity, the UNQUALIFIED load-space experiment parameterizes
 q_p=T V-C q_f, Z=A_f-A_p C, Z P=Q R, U=B+A_p T.
Its first attempted source head was R^(-T)P^T(g_f-C^T g_p), where g=A^T b;
the later attempt explicitly stores Q_head and computes Q_head^T b instead.
Neither repairs the separately observed local reconstruction sensitivity.
No squared Gram matrix is explicitly formed; that is NOT proof that load-space
projection cannot amplify roundoff. Linux extended precision remains required;
binary64/MSVC portability remains unresolved.

All prepared data is value-owned per FIXED geometry/material/constraint epoch.

No moving-solid invalidation/GCL algorithm is implemented here. Sparse and
prepared-response helpers remain in the private archive as unqualified research,
