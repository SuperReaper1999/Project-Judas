# Sprout Patch

A small top-down farming vertical slice built only from Judas's native 2D
systems: sprites, sprite-sheet animation, an editable tilemap with runtime
`setTile` edits, native planar (MK2) physics, runtime UI and modern saves.

Till the soil, plant turnip seeds, water them, wait for them to grow and
harvest. Grow three turnips for the harvest festival.

## Play

Open `Sprout_Patch.judasproj` in the editor and press Play, or run the runtime:

```sh
<build>/judas projects/sprout_patch/Sprout_Patch.judasproj
```

| Touch (mobile) | Desktop | Action |
|---|---|---|
| Drag on the left half of the screen | WASD / arrows / left stick | Walk |
| HOE / SEEDS / WATER buttons | 1 / 2 / 3 | Select a tool |
| USE button | Space or E | Use the tool on the highlighted tile |
| SAVE / LOAD buttons | K / L (also F6 / F7) | Save or load the farm |
| — | R | Restart |

Buttons also respond to mouse clicks. A second finger can press USE or a tool
button while the first finger steers.

## Farming loop

1. **Hoe** grass inside the fence to till it.
2. **Seeds**: plant a seed in tilled soil (you start with 6).
3. **Water**: the can holds 5 waterings. Face the pond (west) and press USE to
   refill. Watered soil turns dark.
4. **Wait**: a crop only grows while its soil is wet. Each growth stage takes
   six seconds and dries the soil, so water again after each stage
   (seed → sprout → young plant → ripe turnip).
5. **Harvest**: face a ripe turnip and press USE with any tool. You get the
   turnip and a seed back, and the soil stays tilled.

The highlighted square shows the tile in front of the farmer; green means USE
will do something there, red shows why not (the HUD explains).

## Edit and extend

- `Assets/game.js`: all farming rules, growth timing, controls, HUD, camera
  and save policy. Tunables (grow time, can size, seeds, goal, field and pond
  rectangles) are script properties in the Inspector.
- `Scenes/main.judas`: the farm grid (select it, then View → 2D authoring →
  Tilemap painter), the farmer, the target cursor and the HUD object.
  The `soil` and `crops` layers start empty; the game edits them at runtime.
  The `solid` layer (fence and pond) is real planar collision.
- `Assets/farm.judassprite` / `farm_tiles.png`: 32×32 tile palette.
- `Assets/hud.judasui`: the HUD. Button layout is read back by `game.js` for
  touch hit-testing, so moving a button in the UI editor keeps it tappable.

Saving stores the tile edits (normal world save of the grid) together with the
farm state in the farmer's script state. Growth timers are in game time, so
they pause while the game is paused or closed.

## Mobile notes

The HUD canvas is resized to the window's aspect ratio at runtime, so buttons
anchor to the real screen corners on any phone. Landscape is recommended:
choose the landscape game orientation when exporting the Android APK (see
`docs/ANDROID.md`). Portrait works, with a wider camera. This slice has been
tested on desktop with synthetic touch input; it has not been played on a phone.

## Art and provenance

`farm_tiles.png` is original art generated by
`tools/demos/sprout_patch/make_art.py`. The farmer reuses Judas's original
`traveller` sprite sheet from the sprite animation workshop. No third-party art.
The project was created by `judas_sprout_patch <repo-root> <fresh-destination>`
(`tools/demos/SproutPatch.cpp`), which uses the editor's own starter, sprite
sheet, tilemap and UI serializers. The delivered project is independently
editable; rerunning the helper is not part of normal editing.
