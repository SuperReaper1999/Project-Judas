# Lucifer / Night Watch

Original editable lighting acceptance courtyard. WASD/mouse, Space jump, F flashlight, LMB shoot bulbs, E patrol motion, Q emergency lights, K/L save/load, R restart, Esc pointer.

The patrol cruiser and pedestrians are project-scripted kinematic assemblies; this fixture tests moving light/caster interaction. Native Vehicles V2 integration is qualified separately. All geometry is original Judas content; DejaVu licence is in Assets/Fonts.
