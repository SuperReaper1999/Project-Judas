# Hair and Fur Lab

Open **hair_fur_lab.judasproj** in the Judas editor and press **Play**. The
showcase contains a stylised fox with a short coat, a skinned horse with an
animated neck and tail, and a turning performer with shoulder-length hair and
a beard. A weather region supplies a crosswind. Hold **C** for a closer
view. The close-up changes between subjects on the simulation clock. Press
**G** to make the performer turn sharply. Hold **V** to see the distant LOD.

Select a groom owner in the hierarchy to edit the fitted patch, guide count,
density, comb direction, or collision capsules. The selected component draws
editor guides and capsules. The saved project works in the standalone runtime
and can be exported through **File → Build & Export… → Export desktop game**.
See [Hair and Fur V2](../../docs/HAIR_AND_FUR.md) for the authoring contract.

The horse and performer are original stylised test fixtures released under
CC0-1.0. Each includes a glTF source and Judas import recipe.
