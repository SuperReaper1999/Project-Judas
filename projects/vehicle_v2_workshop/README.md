# Vehicles V2 Workshop

Editable project-owned driving, native MK2 chassis, finite-width wheels and powertrains.

W/S drive/brake (release and press again to reverse); A/D steer; Space brake; 1/2/3/4 select car/truck/bus/tow rig; K/L save/load; R reload; Esc pause/resume.

The tow rig uses an ordinary ball joint and an unpowered rear-tandem trailer. Service braking acts on both bodies, with torque sized to each supported mass. Releasing W coasts; it does not secretly apply brakes. Paint-free original procedural geometry; DejaVu font licence is in Assets/Fonts. Physics limits and qualification are in the engine Vehicles V2 documentation.
